## 核心知識整理

### 1. 為什麼健康飲食重要？
- 健康飲食不是極端節食或完全不吃某類食物，而是提供身體足夠的能量與營養素來維持日常生理運作。
- 營養素包含**巨量營養素**（碳水化合物、蛋白質、脂肪）、**微量營養素**（維生素、礦物質）與水分。

### 2. 三大營養素的角色
- **碳水化合物**：身體主要的能量來源。可分為較快提供能量的簡單碳水化合物，以及消化較慢、含纖維的複雜碳水化合物（如全穀雜糧：糙米、燕麥、全麥），對血糖與胰島素衝擊較小。
- **蛋白質**：由胺基酸組成，負責建造與修復身體組織、製造酵素與荷爾蒙，並支援免疫系統。日常可從豆、魚、蛋、肉與堅果等來源攝取，建議減少紅肉與香腸、培根等加工肉品。
- **脂肪**：提供高能量密度來源，協助脂溶性維生素吸收與細胞結構維持。應優先選擇不飽和脂肪（如橄欖油、芥花油、酪梨、堅果、魚類），減少飽和脂肪與反式脂肪。

### 3. 新手配餐法：餐盤比例與「我的餐盤」口訣
- **餐盤空間分配（哈佛健康飲食餐盤概念）**：
  - 約 **1/2** 為蔬菜與水果（種類越多越好；馬鈴薯在餐盤分類中不算蔬菜）。
  - 約 **1/4** 為全穀雜糧類。
  - 約 **1/4** 為健康蛋白質。
  - 搭配健康植物油與水分（以水、茶或咖啡為主，限制含糖飲料）。
- **「我的餐盤」六句口訣（國健署）**：
  1. 每天早晚一杯奶
  2. 每餐水果拳頭大
  3. 菜比水果多一點
  4. 飯跟蔬菜一樣多
  5. 豆魚蛋肉一掌心
  6. 堅果種子一茶匙

### 4. 攝取上限與營養標示判讀
- **WHO 每日攝取建議**：
  - 游離糖建議低於總能量攝取的 **10%**（進一步低於 **5%** 更佳）。
  - 飽和脂肪建議低於總能量攝取的 **10%**，工業反式脂肪低於 **1%**。
  - 每日食鹽建議低於 **5 公克**（約相當於鈉低於 **2000 毫克**）。
- **看營養標示的步驟（食藥署）**：
  1. 先看「每一份量」與「本包裝含幾份」，換算實際吃下肚的份數。
  2. 檢視熱量、蛋白質、脂肪（含飽和/反式脂肪）、碳水化合物（含糖）與鈉含量。
  3. 對照「內容物」成分表（依含量多寡排序），辨識原料與糖油添加情形。
